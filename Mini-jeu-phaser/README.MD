# Mini Jeu Phaser

Un petit jeu 2D créé avec Phaser.js.

## Installation

Clonez ce dépôt et ouvrez le fichier `index.html` dans votre navigateur.

## Fonctionnalités

- Déplacement du joueur avec les flèches directionnelles.
- Jeu simple avec un sprite de joueur.

## À propos

Ce jeu est un projet simple pour apprendre à utiliser Phaser.js.
